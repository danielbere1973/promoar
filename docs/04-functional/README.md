# 04-functional

**Domain**: Process
**Knowledge Type**: Support
**Authority**: No

## Qué contiene esta carpeta

Documentos funcionales: describen una funcionalidad o área del producto en detalle
(alcance, comportamiento esperado, reglas de negocio). Un documento funcional puede
agrupar y dar contexto a varios Decision Documents relacionados (`03-decisions/`) que
ya fueron aprobados.

No es un RFC técnico (eso vive en `05-rfc/`) ni un documento estratégico de alto nivel
(eso vive en `01-strategy/` o `02-decision-model/`).

## Convención de nombres

`FN-XXX-nombre-corto.md`, con numeración secuencial ascendente que nunca se reutiliza.

## Relación con otros documentos

- Puede referenciar uno o más Decision Documents de `03-decisions/` que lo originaron.
- Es la base a partir de la cual el CTO deriva un RFC técnico en `05-rfc/` cuando la
  funcionalidad requiere implementación.
